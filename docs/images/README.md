# 截图目录

本目录存放 README 中引用的界面截图。请按下表文件名放置 PNG（文件名区分大小写，
与 README 中的引用路径严格一致）：

| 文件名 | 内容 | 建议 |
| --- | --- | --- |
| `source-properties.png` | NVI 源的属性页 | 展开「NVI 流」下拉，能看到流列表与各开关 |
| `output-settings.png` | 设置 → 输出 中的 NVI 输出 | 能看到编码格式、流名称、发送视频 / 音频 |
| `output-dialog.png` | 工具 →「NVI 输出设置…」对话框 | 能看到状态、启动 / 停止按钮 |
| `preview.png` | 正在接收 NVI 流的 OBS 预览 | 画面内容清晰即可，注意遮挡敏感信息 |

拍摄建议：

- 使用 OBS 的浅色主题截图，尺寸保持一致（例如 1280×720 或窗口原始尺寸）。
- 如需打码，请用不透明色块；本目录下的图片会被直接发布到公开仓库，注意不要包含
  真实设备名、IP、账号等敏感信息。
- 单张图片建议控制在 500 KB 以内，必要时用工具压缩后再提交。

若暂未提供某些截图，README 中对应的图片链接会显示为损坏图标；补齐文件后重新提交即可。
