## 更新截图

1. 文件名保持与上表一致，README 中的引用路径无需改动。
2. 新增或删除截图时，请同时更新上表与 README 的「界面截图」小节。
3. 发布到公开仓库，提交前请遮挡设备名、IP、账号等敏感信息；单张建议控制在 500 KB 以内。
